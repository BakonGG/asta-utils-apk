# Asta Utils

Site oficial (baixar o app + tutorial de instalação):

## 👉 https://bakongg.github.io/asta-utils-apk/

Mantenha suas sequências (streaks) do TikTok sempre vivas, automaticamente.

## Baixar o app

- **Pelo site (recomendado):** https://bakongg.github.io/asta-utils-apk/
- **Direto (APK mais recente):** https://bakongg.github.io/asta-utils-apk/AstaUtils.apk
- **Releases:** https://github.com/BakonGG/asta-utils-apk/releases/latest

Após baixar, abra o arquivo `.apk` para instalar. Se aparecer aviso de "fonte desconhecida", permita a instalação.
